# BK-Automation: guide for Claude

This repository is public. Never add private information to it: no keys, client names, prices,
internal links or planning notes. Private context for Bhuwan's work is kept outside this repo.

## What is here
Four static files and no build step: `index.html` (an older single-page site for BK Automation,
AI replies for NZ tradies and small businesses), and `privacy.html` with an identical copy named
`Privacy.html`.

## Do not break
- `index.html` links to `privacy.html`. Other sites or accounts may point at these URLs, so do not
  rename, move or delete either privacy file without asking Bhuwan.
- `Privacy.html` and `privacy.html` differ only by letter case. On Windows and macOS those two
  names collide, so cloning or editing there can overwrite one with the other. Treat this as a
  known quirk; ask Bhuwan before cleaning it up.
- The project has been idle since April 2026.
